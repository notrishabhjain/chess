# Curriculum content

The three initial Level 1 lessons are `orientation`, `knight`, and `mate`. Each contains localized title, description, objectives, explanation, instruction, hint, success feedback, error coaching, and recap explanation. Hindi content uses consistent learner-facing terms: राजा, रानी, हाथी, ऊँट, घोड़ा, and प्यादा.

New lessons are added by appending a typed `Lesson` definition in `lib/curriculum/lessons.ts`; no lesson engine changes are necessary.
